# The 5 Designs - Company Portfolio

This is the finalized front-end for **The 5 Designs** company portfolio.

## Key Features
- **Minimalist Luxury Aesthetic**: "Quiet Luxury" design system with deep charcoal and warm beige tones.
- **Custom Preloader**: A cinematic "5" branding intro with perfect geometric alignment to the landing page.
- **Smooth Navigation**: Powered by Lenis for silky-smooth scrolling.
- **Interactive UI**: High-end glassmorphism cursor with magnetic interactions and GSAP-powered content reveals.
- **Responsive Design**: Built to perform beautifully across all viewport sizes.

## Project Structure
- `index.html`: The main entry point containing all structure, styles, and logic.
- `index_checkpoint_v1.html` / `index_checkpoint_v2.html`: Historical version backups.
